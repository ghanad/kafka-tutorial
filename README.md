# آموزش تعاملی Apache Kafka

وب‌سایت فارسی و کاملاً آفلاین برای یادگیری Apache Kafka از مفاهیم پایه تا سطح تولید.
تمام متن‌های رابط کاربری و درس‌ها فارسی هستند و کل چیدمان راست‌به‌چپ است.

## وضعیت فعلی

این مخزن در پایان گام ۲ (موتور درس و صفحه پیشرفت) قرار دارد:

- اسکلت React 18 + Vite + TypeScript
- Tailwind CSS با پشتیبانی RTL و تم روشن/تاریک
- فونت Vazirmatn به‌صورت محلی (بدون CDN)
- هدر چسبان، جستجوی درس، تغییر تم و نمایش پیشرفت
- سایدبار راست با فهرست کامل ۹ فصل و ۴۴ درس، وضعیت انتشار و تکمیل
- ذخیره‌سازی Zustand در `localStorage` با نسخه اسکیما
- موتور درس با فهرست مطالب خودکار، نشانک، تکمیل درس و ناوبری درس قبلی/بعدی
- صفحه «پیشرفت من» با درصد پیشرفت، درس‌های تکمیل‌شده، نشانک‌ها و
  پشتیبان‌گیری/بازیابی/پاک‌کردن داده‌ها به‌صورت JSON
- یک درس نمونه کامل (Kafka چیست) برای اثبات کارکرد موتور دوره

درس‌های دیگر در `curriculum.ts` ثبت شده‌اند و با وضعیت «به‌زودی» نمایش داده
می‌شوند تا در گام‌های بعدی محتوای آن‌ها اضافه شود.

## استقرار روی Vercel

این پروژه یک اپلیکیشن تک‌صفحه‌ای (SPA) با Vite است و روی Vercel با تنظیمات
خودکار منتشر می‌شود. فایل `vercel.json` در ریشه مخزن، فرمان ساخت، پوشه خروجی،
بازنویسی مسیرها و هدرهای کش/امنیتی را مشخص می‌کند.

### روش اول: اتصال مخزن GitHub (پیشنهادی)

۱. تغییرات را روی شاخه `main` کامیت و پوش کنید.
۲. در داشبورد Vercel گزینه Add New → Project را بزنید و مخزن
   `ghanad/kafka-tutorial` را Import کنید.
۳. تنظیمات تشخیص خودکار را تأیید کنید: Framework Preset = Vite،
   Build Command = `npm run build`، Output Directory = `dist`. نیازی به متغیر
   محیطی نیست.
۴. دکمه Deploy را بزنید. هر push بعدی روی `main` به‌صورت خودکار منتشر می‌شود.

### روش دوم: Vercel CLI

```bash
npx vercel login
npx vercel --prod
```

برای انتشار پیش‌نمایش بدون اعمال روی دامنه اصلی، `npx vercel` را بدون `--prod`
اجرا کنید. پوشه وضعیت `.vercel` در `.gitignore` قرار دارد.

### نکات مهم

- مسیرها با `HashRouter` کار می‌کنند، بنابراین سمت سرور به تنظیم خاصی برای
  مسیریابی نیاز نیست. بازنویسی موجود در `vercel.json` فقط باعث می‌شود آدرس‌های
  ناشناخته به‌جای صفحه ۴۰۴ میزبان، خود اپلیکیشن را بارگذاری کنند.
- مقدار `base` در `vite.config.ts` برابر `./` است و دارایی‌ها نسبی بارگذاری
  می‌شوند؛ سایت باید در ریشه دامنه منتشر شود (حالت پیش‌فرض Vercel).
- داده‌های کاربر در `localStorage` و وابسته به دامنه است. با انتقال به دامنه
  جدید، پیشرفت قبلی منتقل نمی‌شود؛ از صفحه «پیشرفت من» فایل JSON پشتیبان
  بگیرید و در دامنه جدید وارد کنید.
- هیچ متغیر محیطی لازم نیست و در زمان اجرا هیچ درخواست شبکه‌ای به بیرون انجام
  نمی‌شود.
- Node.js نسخه ۲۲ (پیش‌فرض فعلی Vercel) با پروژه سازگار است و با نسخه محلی
  تفاوتی ندارد.
- هر Preview Deployment دامنه و در نتیجه `localStorage` جداگانه‌ای دارد؛
  داده‌های آزمایشی پیش‌نمایش به دامنه اصلی منتقل نمی‌شوند.

## ساختار پوشه‌ها

```text
src/
  components/
    layout/       هدر، سایدبار، پاورقی و LessonLayout
    ui/           اجزای عمومی رابط کاربری
    diagrams/     نمودارهای SVG
    simulators/   شبیه‌سازهای تعاملی (گام‌های بعدی)
  content/
    curriculum.ts ساختار فصل‌ها و درس‌ها
    lessons/      نوع داده درس، ثبت محتوا و محتوای درس‌ها
  pages/          صفحه اصلی، درس، پیشرفت من، ۴۰۴
  store/          Zustand + persist
  hooks/          هوک‌های مشترک
  utils/          ابزارهای کمکی، پیشرفت و انتقال داده
```

## نکات فنی

- هیچ درخواست شبکه‌ای یا CDN خارجی وجود ندارد؛ فونت‌ها و همه دارایی‌ها در باندل قرار می‌گیرند.
- داده‌های کاربر (پیشرفت، نشانک‌ها، تم و آخرین درس) فقط در
  `localStorage` مرورگر ذخیره می‌شوند.
- کلید ذخیره‌سازی `kafka-tutorial-store` و نسخه فعلی اسکیما `2` است.
- مسیرها با `HashRouter` کار می‌کنند تا استقرار روی هر میزبان استاتیک بدون تنظیم سرور ممکن باشد.
- خروجی پشتیبان یک فایل JSON با کلید `state` است و همان فایل با دکمه «وارد کردن» قابل بازیابی است.
- فهرست مطالب درس‌ها به‌صورت خودکار از سرفصل‌های `h2` و `h3` محتوا ساخته می‌شود.
