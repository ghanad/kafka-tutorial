# آموزش تعاملی Apache Kafka

وب‌سایت فارسی و کاملاً آفلاین برای یادگیری Apache Kafka از مفاهیم پایه تا سطح تولید.
تمام متن‌های رابط کاربری و درس‌ها فارسی هستند و کل چیدمان راست‌به‌چپ است.

## وضعیت فعلی

این مخزن در پایان گام ۲ (موتور درس، آزمون و صفحه پیشرفت) قرار دارد:

- اسکلت React 18 + Vite + TypeScript
- Tailwind CSS با پشتیبانی RTL و تم روشن/تاریک
- فونت Vazirmatn به‌صورت محلی (بدون CDN)
- هدر چسبان، جستجوی درس، تغییر تم و نمایش پیشرفت
- سایدبار راست با فهرست کامل ۹ فصل و ۴۴ درس، وضعیت انتشار و تکمیل
- ذخیره‌سازی Zustand در `localStorage` با نسخه اسکیما
- موتور درس با فهرست مطالب خودکار، یادداشت شخصی، نشانک، تکمیل درس و
  ناوبری درس قبلی/بعدی
- آزمون چندگزینه‌ای و درست/نادرست با توضیح فارسی، ذخیره بهترین امتیاز و تلاش دوباره
- صفحه «پیشرفت من» با درصد پیشرفت، درس‌های تکمیل‌شده، امتیاز آزمون‌ها، نشانک‌ها،
  یادداشت‌ها و پشتیبان‌گیری/بازیابی/پاک‌کردن داده‌ها به‌صورت JSON
- یک درس نمونه کامل (Kafka چیست) برای اثبات کارکرد موتور دوره

درس‌های دیگر در `curriculum.ts` ثبت شده‌اند و با وضعیت «به‌زودی» نمایش داده
می‌شوند تا در گام‌های بعدی محتوای آن‌ها اضافه شود.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه تولید:

```bash
npm run build
npm run preview
```

برای بررسی کد:

```bash
npm run lint
```

## ساختار پوشه‌ها

```text
src/
  components/
    layout/       هدر، سایدبار، پاورقی، LessonLayout و یادداشت درس
    ui/           اجزای عمومی رابط کاربری
    diagrams/     نمودارهای SVG
    simulators/   شبیه‌سازهای تعاملی (گام‌های بعدی)
    quiz/         آزمون پایان درس
  content/
    curriculum.ts ساختار فصل‌ها و درس‌ها
    lessons/      نوع داده درس، ثبت محتوا و محتوای درس‌ها
  pages/          صفحه اصلی، درس، پیشرفت من، ۴۰۴
  store/          Zustand + persist
  hooks/          هوک‌های مشترک
  utils/          ابزارهای کمکی، پیشرفت و انتقال داده
```

## نکات فنی

- هیچ درخواست شبکه‌ای یا CDN خارجی وجود ندارد؛ فونت‌ها و همه دارایی‌ها در باندل قرار می‌گیرند.
- داده‌های کاربر (پیشرفت، امتیاز آزمون‌ها، نشانک‌ها، یادداشت‌ها، تم و آخرین درس) فقط در
  `localStorage` مرورگر ذخیره می‌شوند.
- کلید ذخیره‌سازی `kafka-tutorial-store` و نسخه فعلی اسکیما `1` است.
- مسیرها با `HashRouter` کار می‌کنند تا استقرار روی هر میزبان استاتیک بدون تنظیم سرور ممکن باشد.
- خروجی پشتیبان یک فایل JSON با کلید `state` است و همان فایل با دکمه «وارد کردن» قابل بازیابی است.
- فهرست مطالب درس‌ها به‌صورت خودکار از سرفصل‌های `h2` و `h3` محتوا ساخته می‌شود.
